# Evening Research Skill

Daily post-market research session (5:45 PM ET). Uses web search to find breaking news, analyst commentary, and macro developments that RSS feeds miss. Generates testable hypotheses for the research pipeline.

Designed to be thorough (20 minutes, Opus model with web access).

### Step 2.5: De-dupe before any WebSearch

**Goal: skip queries whose answer is already in our cache or RSS buffer.**
Cuts ~60% of WebSearch calls on a typical evening. Run this *before* any
WebSearch / WebFetch in Steps 3a–3e.

```bash
PYTHONPATH=. python3 <<'PY'
import json, sys
from pathlib import Path
from datetime import datetime, timedelta
from src.research.websearch_cache import WebSearchCache

# 1. Top portfolio symbols already covered by RSS in the last 24h
news_cache = Path.home() / "quant_results/live/news_cache.json"
covered = {}
if news_cache.exists():
    try:
        news = json.load(news_cache.open())
    except Exception:
        news = {}
    cutoff = datetime.now() - timedelta(hours=24)
    for item in (news.get("items") if isinstance(news, dict) else news) or []:
        ts = item.get("published") or item.get("timestamp") or ""
        try:
            t = datetime.fromisoformat(str(ts).replace("Z", "+00:00")).replace(tzinfo=None)
        except Exception:
            continue
        if t < cutoff:
            continue
        for sym in item.get("symbols", []) or []:
            covered.setdefault(sym, []).append(item.get("headline", "")[:100])

print("RSS-covered symbols (last 24h):")
for sym, headlines in sorted(covered.items()):
    print(f"  {sym}: {len(headlines)} headlines")
    for h in headlines[:2]:
        print(f"    - {h}")

# 2. WebSearch cache state
cache = WebSearchCache()
stats = cache.stats()
print(f"\\nWebSearch cache: {stats['live_entries']} live / "
      f"{stats['total_entries']} total entries, TTL={stats['ttl_hours']:.0f}h")
PY
```

**Rules applied during Step 3:**
1. Before issuing a WebSearch for `"<symbol> <topic>"`, check the output above.
   If the symbol appears with ≥2 recent RSS headlines on the topic, SKIP the
   WebSearch. Cite the RSS headlines instead.
2. For remaining queries, check `WebSearchCache().get(query)` first:

### Step 3: Structured Investigation Checklist

Run these 5 focused investigations in order. Spend 2-3 minutes maximum per sub-step.

#### Step 3a: Insider Transaction Check
Read `~/quant_results/live/sec_insider_alerts.json` (generated by SEC EDGAR monitor).
- Review any red flags (2+ insiders selling near 52-week highs)
- For the top 5 portfolio positions by value, if no EDGAR data, search: `"<symbol> insider selling SEC Form 4 2026"`
- Flag any position where insiders sold > $500K in the last 7 days

#### Step 3b: Regulatory Action Check
Read `~/quant_results/live/treasury_alerts.json` (generated by Treasury/OFAC monitor).
- Review any OFAC general licenses, sanctions changes, or enforcement actions
- Search for DOJ, FTC, SEC actions mentioning portfolio symbols
- Specifically search for: `"OFAC general license Venezuela 2026"`, `"DOJ antitrust <thesis sector>"`, `"SEC enforcement <portfolio symbol>"`

#### Step 3c: Market Reaction Analysis
Read `~/quant_results/live/market_reactions.json` (generated by market reaction scorer).
- Focus on REJECTED signals — where market moved opposite to headline
- For each rejected signal, web-search for explanation: why did the market ignore this?
- A rejected signal is the highest-quality intelligence: it tells you what the market actually believes vs what was announced

#### Step 3d: Strategic Analysis Search
For the top 2-3 theses by conviction, search for long-form analysis pieces from:
- Foreign Policy, CSIS, Carnegie Endowment, Soufan Center, War on the Rocks (geopolitical)
- Axios, Reuters Special Reports, Bloomberg Opinion (market strategy)
- Think tank pieces often contain forward-looking assessments that headlines miss
- Search: `"<thesis topic> analysis 2026"`, `"<thesis topic> outlook strategic"`

#### Step 3e: Cross-Reference Alert Review
Read `~/quant_results/live/cross_reference_alerts.json` (generated by cross-reference engine).
- Review any RED FLAG or WARNING alerts
- For each alert, search for supporting evidence or context
- Particularly important: insider divergence (insiders selling while we're buying) and regulatory ceiling (stock at ATH + regulatory action)

### Step 5: Generate Hypotheses

Based on today's market action + web research, generate 2-3 testable hypotheses:

Each hypothesis should include:
- **Statement**: Clear, falsifiable prediction
- **Evidence**: What data supports this?
- **Test plan**: How to validate (backtest, monitor price, check data)
- **Timeline**: When should we check if this played out?
- **Affected theses**: Which existing theses does this impact?
